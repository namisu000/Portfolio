Gaussian Splatting:
Avatar Reconstruction

옷 입은 3D 아바타의 PBR 패스트레이싱 렌더를 Gaussian splatting으로 베이킹해 실시간으로 렌더링하는 작업.
확대해도 의류의 고주파 디테일이 유지되는 것을 목표로 했습니다.

문제

패스트레이싱은 품질은 높지만 느려 실시간에 쓰기 어렵고, 해상도가 낮은 3DGS는 의류의 고주파 디테일을 따라가지 못했습니다.

접근
  1. 고주파 디테일을 살리기 위해 textured Gaussian을 도입하고, 랜덤 split·MCMC 대신 표면 균등 샘플링으로 초기화해 품질과 수렴 시간을 개선
  2. 렌더러 AOV를 GT로 써서 normal·depth 감독과 alpha hull 제약을 loss로 설계
  3. 헤어는 strand 단위로 생성해 두피에 정합하고, 복셀 기반 초기화로 2DGS 학습
  4. 시뮬레이션 대응을 위해 표면 앵커링 스플랫과 표현용 스플랫을 분리

Mesh-to-Gaussian
Splatting

닫힌 삼각형 메시를 relighting 가능한 Gaussian splatting 표현으로 변환하는 방법.
각 Gaussian 안에 DCT 기반 로컬 normal·albedo 필드를 두어, primitive 수를 늘리지 않고 표면 디테일을 보존합니다.

STAGE 1
볼륨 기반 초기화

메시 SDF의 근사 medial axis에 구를 배치하고 타원체로 최적화해 초기 Gaussian 구성

STAGE 2
형상 · 기본 속성 피팅

실루엣·depth 감독으로 형상과 opacity를, 셰이딩 비교로 base normal·albedo를 피팅

STAGE 3
로컬 DCT 필드 · 적응적 분할

공분산 프레임 위 DCT 잔차로 normal·albedo 변화를 표현하고, 부족한 곳만 분할

담당
  • 부피 기반 초기화 아이디어와 부피 채움 방식
  • 부피를 벗어나지 않는 솔리드 학습 방식
  • normal 학습 추가

Gaussian Splat Viewer

외부 3DGS 엔진 없이 OpenGL 셰이더 파이프라인으로 구현한 가우시안 스플랫 뷰어.
깊이 정렬 병목을 GPU로 옮겨 회전 시 끊김을 해소했습니다.

문제

깊이 정렬을 CPU에서 매 프레임 동기적으로 수행해, 시점을 회전할 때 화면이 뚝뚝 끊겼습니다.

개선 Compute Shader

정렬 전 과정(prefix-sum·scatter)을 compute shader 기반 GPU radix sort로 구현해 GPU에 상주시켰습니다. 끊김이 사라지고 정렬 처리량이 크게 개선돼 프레임 저하가 해소됐습니다.

작업 범위

정식 3DGS의 EWA 투영·타일 래스터라이저는 범위 밖으로, 지오메트리 셰이더 빌보드 근사와 하드웨어 블렌딩으로 대체했습니다.
